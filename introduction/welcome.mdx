> Nutgraf builds the agentic capabilities your brands need. You run the brand; Nutgraf builds what powers it.

## What Nutgraf is

Nutgraf is a platform for building agentic capabilities for brands. Every brand business has production needs — content, products, tools, workflows. Nutgraf gives each of your brands its own set of agentic capabilities to handle those needs, with more capabilities added as the platform evolves.

The foundational unit in Nutgraf is the **Brand**. Each Brand is a persistent, isolated workspace for one brand business — holding its brief, voice, creative direction, and the history of everything built inside it. You can run multiple Brands from a single account, and nothing crosses between them.

Inside a Brand, you invoke **Computers** — agentic systems that use a computer to complete a defined task and deliver a specific outcome. Two Computers are available today: one for producing video, one for building apps. More are coming as Nutgraf expands what it can build for your brands.

## What you can do with Nutgraf

- **Run multiple brand businesses** from one account. Each Brand is fully isolated with its own brief, creative direction, and build history.
- **Build brand video.** The video Computer takes a topic or brief and delivers a broadcast-ready first draft — scripting, narration, animation, and rendering — in approximately 15 minutes.
- **Build brand apps.** The code Computer takes a natural-language description and builds an interactive web or mobile app, with the result visible on a live preview canvas as it works.
- **Direct the output conversationally.** Review what was built, describe changes in plain language, and see revisions in the same session.

## How Nutgraf is organised

Everything starts with a **Brand**. A Brand holds the context — brief, voice, presenter setup — that every Computer inherits when you invoke it. You define the brand once; every Computer run inside it starts from that foundation.

**Computers** are the agentic systems that do the building. Each Computer is designed for a specific type of outcome. When you invoke a Computer inside a Brand, it takes the brief from the workspace and goes to work.

**Stories** is the daily session bar inside each Brand. Every Computer run and Brand conversation appears here, organised by date. You can track active runs, review completed builds, and continue any session from where you left off.
