> Stories are the daily session bar inside a Brand. Every Computer run and Brand conversation appears here, organised by date, so you can track what is running and pick up any session where it left off.

## What it is

The Stories bar sits at the top of your Brand workspace, grouped by date. Each entry is a session — either a direct conversation with the Brand, or a Computer run (Video or Code) tied to a specific topic or task. Sessions stay open and resumable. When a Computer finishes producing a deliverable, the story for that run holds the result, your feedback thread, and any revisions you requested.

Stories give you a persistent record of everything that happened inside a Brand on a given day. You can navigate backward to review a previous day's work, continue a refinement conversation, or share a specific story with a collaborator.

## How to use it

### Reading the Stories bar

The Stories bar shows a horizontal row of session tabs beneath the date header. The first tab, marked with a star, is the Brand conversation — your direct channel to the Brand agent for questions, brief updates, or general direction. The remaining tabs represent Computer runs, each labelled with the Computer type and the topic or task it was given.

### Opening a story

Click any tab to open that session. The conversation history, delivered artefacts, and any follow-up exchanges load immediately. You can continue the conversation from this point — request a scene revision, ask a follow-up question, or review the output.

### Navigating between days

Use the date navigation at the top of the workspace to move between days. Each day shows its own set of story tabs. Stories from previous days are read-only unless the Computer run is still active.

## What You Need to Know

### Story types

| Tab indicator | What it represents |
| :- | :- |
| ★ Brand | Direct conversation with the Brand agent |
| Video | A Creative Studio run tied to a specific topic |
| Code | A Product Development run tied to a specific task |

### Persistence and resumability

Stories persist indefinitely within a Brand. A Computer run that is still in progress appears in the Stories bar with an active status indicator. You can open it, observe the progress, and add input if the Computer pauses to ask a question.

### Sharing a story

You can share a specific story with a collaborator by copying the story link. The recipient must have access to the Brand to view it.

## Tips

- **Use the Brand conversation tab for direction-setting, not task execution.** Save Computer invocations for defined deliverables — use the Brand tab for questions, brief refinements, or planning.
- **Review stories from the previous day before starting new runs.** Unfinished refinements or pending revisions are easier to catch before you add new work.
- **Label Computer runs with specific topics.** A story called "AI safety for founders — explainer" is faster to find again than one with a generic or blank title.

## Frequently Asked Questions

<AccordionGroup>
  <Accordion title="Do stories expire or get deleted?">
    Stories persist as long as your Brand exists. There is no automatic expiry.
  </Accordion>
  <Accordion title="Can I have multiple Computer runs open at the same time?">
    Yes. Each Computer run is an independent story tab. You can have a Video run and a Code run active simultaneously under the same Brand, each drawing from the shared credit pool.
  </Accordion>
  <Accordion title="Can I resume a refinement conversation after closing the browser?">
    Yes. The full conversation history is stored with the story. Reopen the tab at any time to continue where you left off.
  </Accordion>
</AccordionGroup>
